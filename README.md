# KyonRLStepping package

Collection of Kyon-specific implementations for RL-augmented MPC within the IBRIDO framework.

In particular, this repository hosts:
- MPC configurations for Kyon and Unitree's B2-w robots
- Joint impedance configurations
- Helper launchers and configurations to run the robots within [xbot_mujoco]()
- [MPCViz](https://github.com/AndrePatri/MPCViz) robot-specific configuration and helps to debug and visualize MPC plans
